# Mouse Dynamics-Based Intrusion Detection

This project implements a continuous authentication system using Mouse Dynamics, Asymmetric Recurrence Plots (ARP), and Vision Transformers (ViT).

## Features
- Mouse dynamics based authentication
- Asymmetric Recurrence Plot generation
- Vision Transformer classifier
- Efficient Attention mechanism
- GHM Loss implementation

## Dataset
- DFL Mouse Dataset

## Technologies Used
- Python
- PyTorch
- NumPy
- Matplotlib
- Vision Transformers

## Results
- Mean AUC: 0.7800
- Mean EER: 0.2756
